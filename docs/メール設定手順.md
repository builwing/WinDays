# メール設定手順（Xserver SMTP・WinTask `backend/.env`）

WinDays / WinTask のメール送信を、Xserver（`winroad.jp`）の SMTP で行うための設定手順。
設定先は WinTask の本番 `backend/.env`（`/var/www/WinTask/backend/.env`）。要件は [要件定義書 §7.4](要件定義書.md#74-メール配信基盤) を参照。

---

## 1. Xserver サーバーパネルでの準備

1. **メールアカウント設定** → `winroad.jp` → `no-reply@winroad.jp` を作成（容量は最小で可。バウンス受信用なので 500MB 程度あれば十分）
2. **DMARC設定** → `winroad.jp` に `p=none`・レポート先 `info@winroad.jp` で追加（SPF・DKIM は設定済み）

## 2. `backend/.env` の書き換え

現在の `.env` には次の 3 行だけがある（35〜37 行目付近）。

```dotenv
MAIL_MAILER=log
MAIL_FROM_ADDRESS="no-reply@task.winroad.org"
MAIL_FROM_NAME="${APP_NAME}"
```

これを以下に置き換える。**`MAIL_PASSWORD` は手元で入力する**（このリポジトリや Claude には渡さない）。

```dotenv
# --- Mail（Xserver SMTP・winroad.jp）---
MAIL_MAILER=smtp
MAIL_SCHEME=smtps
MAIL_HOST=sv14762.xserver.jp
MAIL_PORT=465
MAIL_USERNAME=no-reply@winroad.jp
MAIL_PASSWORD=ここにXserverで設定したパスワード
MAIL_FROM_ADDRESS="no-reply@winroad.jp"
MAIL_FROM_NAME="${APP_NAME}"
```

補足:

- Laravel 13 の `config/mail.php` は `MAIL_ENCRYPTION` ではなく **`MAIL_SCHEME`** を見る。ポート 465（SSL）なら `smtps`。587（STARTTLS）を使う場合は `MAIL_SCHEME=smtp`・`MAIL_PORT=587` にする。
- パスワードに `#` や空白、`"` を含む場合はダブルクォートで囲む（例: `MAIL_PASSWORD="p#ss word"`）。
- `MAIL_FROM_NAME` は当面 `${APP_NAME}`（WinTask）のまま。WinDays のメールは Mailable 側で送信者名を「WinDays」に上書きする。
- Reply-To（ユーザーが返信したときの受け先）は Mailable 側で `info@winroad.jp` を指定する。`.env` には不要。

## 3. キューの有効化（同時に行う）

メール送信をキュー経由にし、送信レートを絞る。`.env` の `QUEUE_CONNECTION` を変更する。

```dotenv
QUEUE_CONNECTION=database
```

- `jobs` / `failed_jobs` テーブルが無ければ `php artisan queue:table` → migrate が必要（WinTask 側のデプロイスクリプトで行う）。
- `php artisan queue:work` の systemd 常駐は Phase 0 のデプロイスクリプトで設定する。**それまでは `sync` のままでよい**（`.env` のメール設定だけ先に入れて動作確認できる）。

## 4. 反映と動作確認

`.env` を変更しただけでは反映されない（config キャッシュ済みのため）。main に変更が無くても、キャッシュ再構築だけ実行する。

```bash
sudo bash deploy/backend-cache.sh
```

テスト送信（自分のアドレスに 1 通送る。`you@example.com` を置き換える）:

```bash
cd /var/www/WinTask/backend && sudo -u www-data php artisan tinker --execute="Mail::raw('WinDays SMTP test', fn(\$m) => \$m->to('you@example.com')->subject('WinDays SMTP test'));"
```

確認ポイント:

- 届いたメールのヘッダで `spf=pass`・`dkim=pass`（Gmail なら「メッセージのソースを表示」）
- 迷惑メールに入らないこと
- 失敗時は `backend/storage/logs/laravel.log` に SMTP のエラーが出る。`535` は認証失敗（ユーザー名はアドレス全体・パスワード再確認）、接続タイムアウトは VPS から `sv14762.xserver.jp:465` への到達性を `nc -vz sv14762.xserver.jp 465` で確認

## 5. 戻し方

送信を止めたいときは `MAIL_MAILER=log` に戻して `sudo bash deploy/backend-cache.sh`。ログ出力（`storage/logs/laravel.log`）に切り替わる。
