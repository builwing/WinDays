# メール設定手順（VPS Postfix・WinTask `backend/.env`）

WinDays / WinTask のメール送信を、VPS 上の Postfix（`mail.winroad.org`）から行うための設定手順。
設定先は WinTask の本番 `backend/.env`（`/var/www/WinTask/backend/.env`）。要件は [要件定義書 §7.4](要件定義書.md#74-メール配信基盤) を参照。

> Xserver（`winroad.jp`）の SMTP は、Xserver 側が VPS の IP を全ポートで遮断しているため使えない（2026-09-09 確認）。

---

## 0. VPS 側の現状（確認済み・変更不要）

| 項目 | 状態 |
| --- | --- |
| Postfix | `myhostname = mail.winroad.org`、`virtual_mailbox_domains = winroad.org`、`mynetworks = 127.0.0.0/8`（localhost からは認証なしで送信可） |
| opendkim | 稼働中。Postfix の milter（`inet:localhost:8891`）として接続済み。鍵 `/etc/opendkim/keys/winroad.org/mail.private`（selector `mail`） |
| DNS | SPF `v=spf1 a mx ip4:160.251.215.3 -all`／DKIM `mail._domainkey.winroad.org` 公開済み／DMARC `p=none`／PTR `mail.winroad.org` |
| 外向き 25 番 | Gmail の MX へ接続可 |
| 受信箱 | `info@winroad.org` のみ。`postmaster@`・`abuse@` は `info@` へ転送 |

## 1. Postfix に `no-reply@winroad.org` の転送先を追加（要 sudo・1 回だけ）

`no-reply@winroad.org` 宛のバウンスを `info@winroad.org` で受けるためのエイリアス。`virtual_alias` は `texthash` 形式なので `postmap` は不要で、reload だけで反映される。

```bash
sudo bash -c 'grep -q "^no-reply@winroad.org" /etc/postfix/virtual_alias || echo "no-reply@winroad.org  info@winroad.org" >> /etc/postfix/virtual_alias; systemctl reload postfix; tail -n 3 /etc/postfix/virtual_alias'
```

## 2. `backend/.env` の書き換え

`MAIL_` で始まる行をすべて次に置き換える（Xserver 用の `MAIL_HOST=sv14762…` などが残っていれば削除）。パスワードは不要。

```dotenv
# --- Mail（VPS Postfix / mail.winroad.org・sendmail 経由）---
MAIL_MAILER=sendmail
MAIL_FROM_ADDRESS="no-reply@winroad.org"
MAIL_FROM_NAME="${APP_NAME}"
```

補足:

- **`smtp` で `127.0.0.1:25` に接続する方式は使わない。** Postfix が STARTTLS を提供しているため Laravel が自動で TLS に切り替え、証明書名 `mail.winroad.org` と接続先 `127.0.0.1` の不一致で失敗する（WinTask の `config/mail.php` には自動 TLS を切る設定が無い）。`sendmail` 経路（`/usr/sbin/sendmail -bs -i`）はネットワークを使わず Postfix の pickup に直接渡すため、この問題が起きない。
- `sendmail` 経由でも `non_smtpd_milters = inet:localhost:8891` により opendkim が署名する。
- `MAIL_FROM_NAME` は当面 `${APP_NAME}`（WinTask）のまま。WinDays のメールは Mailable 側で送信者名を「WinDays」に上書きする。
- Reply-To（ユーザーが返信したときの受け先）は Mailable 側で `info@winroad.org` を指定する。`.env` には不要。

## 3. キューの有効化（Phase 0 のデプロイで行う）

```dotenv
QUEUE_CONNECTION=database
```

- `jobs` / `failed_jobs` テーブルと `php artisan queue:work` の systemd 常駐は Phase 0 のデプロイスクリプトで設定する。**それまでは `sync` のままでよい**。

## 4. 反映と動作確認

`.env` を変更しただけでは反映されない（config キャッシュ済み）。WinTask のルートで実行する。

```bash
cd /var/www/WinTask && sudo bash deploy/backend-cache.sh
```

テスト送信（`you@example.com` を置き換える。PHP 部分はシングルクォートで囲む）:

```bash
cd /var/www/WinTask/backend && sudo -u www-data XDG_CONFIG_HOME=/tmp php artisan tinker --execute='Mail::raw("WinDays SMTP test", fn($m) => $m->to("you@example.com")->subject("WinDays SMTP test")); echo "sent";'
```

確認ポイント:

- 届いたメールのヘッダ（Gmail なら「メッセージのソースを表示」）で `spf=pass`・`dkim=pass header.d=winroad.org`・`dmarc=pass`
- 迷惑メールに入らないこと
- 送信ログ: `sudo tail -n 20 /var/log/mail.log`（`status=sent` と `DKIM-Signature field added` が出る）
- 失敗時は `backend/storage/logs/laravel.log`。`sendmail` の実行エラーなら `/usr/sbin/sendmail` の存在と Postfix の稼働（`systemctl status postfix`）を確認

## 5. 確認結果（2026-09-09）

本番 `backend/.env` を `MAIL_MAILER=sendmail` に切替え、`wingnakada@gmail.com` 宛にテスト送信。Gmail の「原文を表示」で次を確認した。

| 項目 | 結果 |
| --- | --- |
| SPF | pass（`designates 160.251.215.3 as permitted sender`） |
| DKIM | pass（`header.i=@winroad.org header.s=mail`） |
| DMARC | pass（`p=NONE`） |
| 配送 | `mail.winroad.org` → `mx.google.com` を TLS 1.3 で配送、受信箱に到達 |

差出人表示は `WinTask <no-reply@winroad.org>`（`MAIL_FROM_NAME=${APP_NAME}`）。WinDays のメールは Mailable 側で「WinDays」に上書きする。

## 6. 戻し方

送信を止めたいときは `MAIL_MAILER=log` に戻して `cd /var/www/WinTask && sudo bash deploy/backend-cache.sh`。
