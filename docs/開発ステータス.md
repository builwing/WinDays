### 本番反映の手順（記録。次回以降のバックエンド反映は同じ流れ）

```bash
cd /var/www/WinTask && sudo bash deploy/windays-phase0-deploy.sh   # ff-merge + migrate + cache
cd /var/www/WinTask && sudo bash deploy/windays-api-domain.sh      # api.days.winroad.org 証明書 + vhost
cd /var/www/WinDays && bash deploy/web-reflect.sh                  # web/build を作成
cd /var/www/WinDays && sudo bash deploy/days-domain.sh             # days.winroad.org 証明書 + vhost
```

注意: `windays-phase0-deploy.sh` の autoload 再生成は `hide` で実行する（修正済み）。`/up` は CORS 対象外なのでブラウザからの疎通確認は `/api/v1/me`（401）を使う。
